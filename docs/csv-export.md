# ส่งออก CSV — issue #12

ใน `/dashboard` ส่วน **รายการของคุณ** ใช้ **ค้นหาและกรอง** แล้วกด **ดาวน์โหลด CSV** ไฟล์ `pocketapp-transactions.csv` รวมทุกรายการที่ตรงเงื่อนไข แม้ยังไม่กดดูหน้าถัดไป การแก้ช่องกรองโดยยังไม่กดใช้ไม่เปลี่ยนเงื่อนไขส่งออก ปุ่มปิดระหว่างโหลดรายการหรือเมื่อโหลดรายการล้มเหลว เพื่อไม่ส่งออกด้วยเงื่อนไขที่ยังแสดงผลไม่สำเร็จ เมื่อดาวน์โหลดล้มเหลวจะแสดงข้อผิดพลาดและกดลองใหม่ได้

## เงื่อนไขเดียวกับรายการ

- ค้นหาเฉพาะคำอธิบายแบบไม่สนตัวพิมพ์ใหญ่เล็ก ใช้ `%`, `_`, `\` เป็นอักษรจริง
- วันที่เริ่มต้นและสิ้นสุดรวมวันขอบเขต ใช้วันที่ธุรกิจไทย ไม่แปลงตาม timezone ของอุปกรณ์
- หมวดต้องตรงกับหมวดที่กรอง รวมหมวดที่เก็บแล้วในประวัติ
- ประเภทรายรับ (`INCOME`) ส่งออกเฉพาะรายรับ ประเภทรายจ่าย (`EXPENSE`) รวมรายจ่ายและเงินคืนที่ตรงเงื่อนไข ไม่ระบุประเภทจะรวมทั้งสามชนิด

เงินคืนใช้ **วันที่ได้รับจริง** และ **คำอธิบายของเงินคืนเอง** พร้อมหมวดปัจจุบันของรายจ่ายต้นทาง ดังนั้นไฟล์อาจมีเงินคืนแม้รายจ่ายต้นทางอยู่นอกช่วงหรือไม่ตรงคำค้น หน้ารายการยังแสดงรายรับ/รายจ่าย ส่วนประวัติเงินคืนเปิดได้จากรายจ่ายต้นทางตามเดิม มีคำอธิบายใต้ปุ่มว่าการส่งออกรวมเงินคืนด้วย

## รูปแบบไฟล์

UTF-8 พร้อม BOM สำหรับภาษาไทย แต่ละ record ลงท้าย CRLF ทุกค่า quote และซ้อนอัญประกาศเป็น `""` จึงเก็บ comma/อัญประกาศ/ขึ้นบรรทัดใหม่ในข้อความได้ ชุดไม่มีข้อมูลยังมี BOM และ header

คอลัมน์: `id,date,type,category,amount,description,refund_of`

- `id`: ID ของรายการหรือเงินคืน
- `date`: `YYYY-MM-DD`
- `type`: `INCOME`, `EXPENSE`, `REFUND`
- `category`: ชื่อหมวด รวมชื่อที่เปลี่ยนใหม่และหมวดที่เก็บแล้ว
- `amount`: จำนวนบาทฐานสิบสองตำแหน่งจากจำนวนเต็มสตางค์ เช่น `0.01`, `21474836.47` ทุกชนิดเป็นยอดบวก เงินคืนลดรายจ่ายตาม type `REFUND`
- `description`: คำอธิบาย หรือข้อความว่างเมื่อไม่มี
- `refund_of`: ID ของรายจ่ายต้นทางสำหรับเงินคืน หรือว่างสำหรับรายการทั่วไป อ้างอิงได้แม้ต้นทางไม่ได้อยู่ในไฟล์

เรียงวันที่ล่าสุดก่อน ตามด้วยเวลาสร้างและ ID ล่าสุดก่อน การอ่านรายการและเงินคืนใช้ database snapshot เดียวกัน ข้อความชื่อหมวด/คำอธิบายที่เริ่มเป็นสูตร (`=`, `+`, `-`, `@` รวมกรณีมี whitespace นำหน้า) หรือเริ่ม tab/CR/LF จะเติม apostrophe นำหน้าเพื่อไม่ให้โปรแกรม spreadsheet รันสูตร ข้อความทั่วไปคงเดิม ข้อมูลในฐานข้อมูลไม่เปลี่ยน

## HTTP และความเป็นส่วนตัว

`GET /api/transactions/export` รับ query `search`, `startDate`, `endDate`, `type`, `categoryId` เหมือน `/api/transactions` ใช้ตัวสร้างเงื่อนไขเดียวกัน ไม่รับ `cursor` เพราะส่งออกทั้งชุด และไม่รับ `userId` หรือ field อื่น

ตรวจ session และจำกัดเจ้าของทั้งรายการ เงินคืน และรายจ่ายต้นทางทุกครั้ง ชี้หมวดของคนอื่นได้ไฟล์ว่าง ไม่มี session ตอบ 401 query ผิดตอบ 400 ระบบล้มเหลวตอบ 503 แบบ JSON โดยไม่เริ่มดาวน์โหลดไฟล์ผิดพลาด

ไฟล์สำเร็จตอบ `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment`, `Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff` ไม่มี migration เพิ่มใน ticket นี้

## ตรวจรับ

`pnpm test:e2e csv-export.spec.ts` ทดสอบ HTTP และ browser download บน desktop/mobile กับ PostgreSQL แยก ครอบคลุมตัวกรองเดี่ยว/ร่วม ผลตรงกับหน้ารายการ เงินคืนข้ามเดือนซึ่งต้นทางไม่อยู่ในไฟล์ จำนวนเงินถึงสตางค์ ภาษาไทย/quotes/newlines หมวดเก็บแล้ว รายการเกินหนึ่งหน้า ไฟล์ว่าง formula escaping สิทธิ์สองบัญชี การใช้ตัวกรองที่กดใช้แล้ว และ download failure/retry/pending
