# T10: เปรียบเทียบเดือนด้วยช่วงเวลาที่เทียบกันได้

**Status:** ready-for-agent

**Published:** https://github.com/tanakron1748q/pocketapp/issues/11

## Parent

https://github.com/tanakron1748q/pocketapp/issues/1

## What to build

Dashboard เปรียบเทียบเดือนปัจจุบันกับช่วงวันที่เท่ากันของเดือนก่อน และเทียบเต็มเดือนสำหรับเดือนที่จบแล้ว

## Acceptance criteria

- [ ] เดือนปัจจุบันเทียบช่วงวันที่ที่ผ่านไปกับเดือนก่อน พร้อมแสดงช่วงวันที่ทั้งคู่
- [ ] เดือนที่จบแล้วเทียบเต็มเดือนกับเดือนก่อน
- [ ] รองรับเดือนสั้น/ยาว ปีเปลี่ยน และปีอธิกสุรทินโดยไม่รวมวันนอกช่วงเปรียบเทียบ
- [ ] ฐานเปรียบเทียบเป็นศูนย์และยอดสุทธิติดลบแสดงผลที่เข้าใจได้ ไม่มี NaN หรือ Infinity
- [ ] มี browser/HTTP tests ที่ควบคุมวันที่ทดสอบและตรวจยอดกับช่วงวันที่จริงผ่านแอป
