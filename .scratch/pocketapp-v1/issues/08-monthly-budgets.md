# T08: ตั้งงบรายเดือนและติดตามงบคงเหลือ

**Status:** ready-for-agent

**Published:** https://github.com/tanakron1748q/pocketapp/issues/9

## Parent

https://github.com/tanakron1748q/pocketapp/issues/1

## What to build

ผู้ใช้ตั้งงบแยกหมวด ใช้ค่าตั้งต้นต่อเดือนถัดไป ปรับเฉพาะเดือน และดูงบใช้ไป/เหลือจากรายจ่ายสุทธิจริง

## Acceptance criteria

- [ ] ตั้งงบหมวดรายจ่ายส่วนตัวในเดือนหนึ่ง มีค่าตั้งต้นใช้ต่อเดือนถัดไปและ override เฉพาะเดือนได้
- [ ] การปรับเฉพาะเดือนไม่เขียนทับงบเดือนอื่น และไม่ทบเงินงบเหลือข้ามเดือน
- [ ] งบคงเหลือเท่ากับงบลบรายจ่ายสุทธิของหมวดในเดือนนั้น รวมเงินคืนตามเดือนที่รับ
- [ ] แสดงใช้เกินงบได้และยังบันทึกรายจ่ายต่อได้ การเข้าถึงงบของ User อื่นถูกปฏิเสธ
- [ ] มี browser/HTTP tests สำหรับค่าตั้งต้น override ข้ามเดือน ไม่มี rollover เงินคืน และใช้เกินงบ
