# T07: บันทึกและแก้ไขเงินคืนโดยยอดไม่เกินต้นทาง

**Status:** ready-for-agent

**Published:** https://github.com/tanakron1748q/pocketapp/issues/8

## Parent

https://github.com/tanakron1748q/pocketapp/issues/1

## What to build

ผู้ใช้คืนเงินบางส่วนหรือเต็มจำนวนอ้างอิงรายจ่ายเดิมได้ พร้อมประวัติและรายจ่ายสุทธิที่ถูกต้อง แม้ใช้งานพร้อมกันสองอุปกรณ์

## Acceptance criteria

- [ ] เพิ่ม แก้ไข และลบเงินคืนที่อ้างอิงรายจ่ายของตัวเองได้ เห็นเงินคืนและรายการต้นทางในหน้าจอ
- [ ] นับเงินคืนในวันที่ได้รับเงินจริง ลดรายจ่ายของหมวดต้นทางและไม่เพิ่มรายรับ รองรับการคืนข้ามเดือนและยอดสุทธิติดลบ
- [ ] ยอดคืนรวมไม่เกินรายจ่ายต้นทาง และจำนวนเงิน/วันที่ต้องผ่านกติกาเดียวกับรายการจริง
- [ ] ห้ามลบรายจ่ายที่ยังมีเงินคืน หรือแก้ยอดให้ต่ำกว่ายอดคืนสะสม จนกว่าจะแก้หรือลบเงินคืนที่ขัดกัน; การอ้างอิงข้าม User ถูกปฏิเสธ
- [ ] ทดสอบผ่าน browser/HTTP กับ PostgreSQL จริง รวมสองคำขอคืนเงินพร้อมกันและการแก้/ลบต้นทางชนกับเงินคืน โดย invariants ยังถูกต้อง
