## What to build

ผู้ใช้เปิดภาพรวมแล้วเห็นรายรับ รายจ่ายสุทธิ เงินเหลือ กราฟตามหมวด งบ และรายการล่าสุด พร้อมเลือกเดือนย้อนหลัง

## Acceptance criteria

- [ ] เริ่มต้นเดือนปัจจุบันและเปลี่ยนดูเดือนย้อนหลังได้ตามเวลาไทย
- [ ] คำนวณรายรับ รายจ่ายสุทธิ และเงินเหลือประจำเดือนตรงกับรายการและเงินคืนในช่วงนั้น
- [ ] แสดงกราฟหมวด งบใช้ไป/เหลือ และรายการล่าสุดของ User นั้น
- [ ] กราฟรองรับรายจ่ายสุทธิติดลบจากเงินคืน และไม่สื่อว่าเงินเหลือประจำเดือนคือยอดเงินธนาคารทั้งหมด
- [ ] มี browser/HTTP tests ครอบคลุมเดือนว่าง เดือนย้อนหลัง เงินคืนข้ามเดือน ค่าติดลบ และไม่รั่วข้อมูลผ่านรายงานหรือ cache
